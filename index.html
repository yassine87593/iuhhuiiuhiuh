⚡ À savoir

Jeux intégrés : les mini-jeux inclus dans PIXEL ARENA fonctionnent directement ici.

Jeux externes : un éditeur peut bloquer l'affichage dans un lecteur intégré. Si cela arrive, ce n'est pas un bug que le site peut contourner.

Émulation : pour les jeux PS1/PSP, utilise uniquement tes propres fichiers de jeu et BIOS lorsque requis. Cette première version ne fournit aucun jeu protégé.

Performances : le site ne force pas une limite de 60 FPS sur tous les jeux; cela dépend du jeu et de l'appareil.
